# AI Medical Diagnosis Assistant

## Overview
An AI-based medical diagnosis assistant that analyzes user-reported symptoms and generates preliminary, explainable diagnostic insights using Machine Learning and Generative AI.

## Features
- Symptom analysis using structured decision logic
- Context-aware diagnostic explanations using Generative AI
- Modular and scalable design

## Tech Stack
- Python
- Machine Learning
- Generative AI (Gemini API)

## How It Works
1. User inputs symptoms
2. System processes symptoms using ML-based and rule-based logic
3. Generative AI produces human-readable diagnostic output
